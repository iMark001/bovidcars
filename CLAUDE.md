# bovidcars — каталог премиальных авто из Грузии

Статичный сайт-каталог на GitHub Pages (`https://imark001.github.io/bovidcars/`, репозиторий `iMark001/bovidcars`, публикация из `/docs`). Исходник — PDF-КП салонов, из них собираются русскоязычные страницы и PDF в стиле Apple (`DESIGN-apple.md`).

## Стек
Python 3.11 + Jinja2 + Pillow + Playwright (Chromium) + poppler (`pdfimages`, `pdftotext`). Фронтенд: чистые HTML/CSS/JS без фреймворков.

## Структура
- `data/site.json` — бренд, контакты, порядок марок, резервный курс EUR→USD.
- `data/cars/<slug>.json` — одно авто = один файл, **единственный источник истины**.
- `data/brands/*.svg` — логотипы марок.
- `tools/` — `extract.py` (PDF → work/), `images.py` (фото → WebP), `validate.py`, `build.py` (→ docs/), `pdf.py` (→ docs/pdf/).
- `templates/`, `assets/` — шаблоны Jinja и CSS/JS.
- `docs/` — собранный сайт, генерируется, руками не правится.
- `PDF дд.мм.гггг/`, `work/`, `contacts.txt` — в .gitignore.

## Команды
```
python3 tools/extract.py "PDF 25.09.2026"   # сырой текст и фото в work/
python3 tools/validate.py                   # проверка data/cars/*.json
python3 tools/build.py                      # сборка docs/
python3 tools/pdf.py                        # PDF (с ценой и без) в docs/pdf/
python3 -m pytest tests/                    # тесты
python3 -m http.server 8000 -d docs         # превью: http://localhost:8000/
```

## Правила контента (жёсткие)
- Порядок марок: **Volvo → Land Rover → Porsche**, остальные после (по алфавиту). Внутри марки новые (`addedDate`) первыми.
- Никаких выдумок. Данные только из КП; пробелы дополняются из официальных источников производителя, поле отмечается в `supplemented[]`, список показывается пользователю на утверждение.
- Список запрещённых слов для автотеста — `tests/forbidden.local.txt` (локально, не в git). Новые имена/телефоны салонов добавлять туда.
- Удалять из КП: менеджеров салона и их телефоны, имя покупателя, название дилера, Porsche Code, дисклеймеры, экологический блок (CO₂/Euro6e), гарантию салона.
- Оставлять: габариты/массу, запас хода/зарядку.
- Перевод на русский; названия брендов и систем (Pilot Assist, Bowers & Wilkins, Terrain Response 2) — в оригинале.
- VIN показывается полностью; если нет — «№ конфигурации».
- Цены: Volvo EX90 по умолчанию 73 000 €; остальные — спросить пользователя по VIN. Для LR — спеццена салона.
- Отображение цены: **всегда сначала евро, затем доллары, без «≈»** и без переключателя валют. Пересчёт точный (до единиц) по курсу ЕЦБ (frankfurter.dev); в PDF — курс на дату сборки.
- **Не писать на сайте, что авто из Грузии / в наличии в Тбилиси.** Посыл — поставка в Россию под ключ. Подпись к цене: «Стоимость доставки в Россию под ключ рассчитывается индивидуально».
- Статусы: `available` (В наличии), `in_transit` (В пути), `reserved` (Забронировано), `sold` (Продано).
- Сайт закрыт от индексации (noindex + robots.txt).

## Процесс для новой папки КП
1. `extract.py` по новой папке → разбор текста/фото в `work/`.
2. Составить `data/cars/<slug>.json` (`addedDate` = дата из имени папки, статус «В наличии», если не сказано иное).
3. Спросить у пользователя цену по каждому VIN.
4. `validate.py` + тесты → `build.py` + `pdf.py` → превью в браузере.
5. После «ОК» — commit + push.
