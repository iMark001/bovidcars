# MEMORY — bovidcars

## 25.09.2026 — старт проекта
- Бренд **bovidcars**. Стиль Apple (DESIGN-apple.md): светлые и тёмные блоки, один акцент.
- Решения интервью зафиксированы в CLAUDE.md (правила контента) и в TASKS.md.
- Курс €/$: авто-курс ЕЦБ через frankfurter.app на сайте; в PDF — курс на дату сборки.
- PDF: готовые файлы, A4 вертикальный, две версии (с ценой / без цены), QR на страницу, контакты, дата.
- Фото: основа из PDF; допускаются официальные рендеры того же цвета и комплектации.
- Хостинг: GitHub Pages, аккаунт gh `iMark001`, noindex.
- Особенности исходников: КП LR и Porsche частично на грузинском; у LR цены в USD с «спеццена»; у Volvo цены нет (73 000 €); у двух Volvo нет VIN — используем ID конфигурации (13335424, 12949182).

## 25.09.2026 — правки после первого превью
- Убраны упоминания Грузии/Тбилиси; hero: «Премиальные автомобили под ключ», посыл — поставка в РФ под ключ.
- Цены: всегда € первой строкой, $ второй, без «≈», переключатель валют удалён. Пересчёт точный до единиц.
- Карточки: фото без фона (Volvo) — на сером с тенью; обычные фото вписываются целиком (object-fit: contain), поля заливаются медианным цветом краёв фото (build.edge_color).
- Фото LR из КП имеют чёрную рамку-тень ~1.8% стороны — images.trim_frame срезает её, если все 4 края чёрные.
- PDF: для печати build делает JPEG 1600px (img/<slug>/print/), иначе Chrome вшивает WebP без сжатия (10 МБ → ~1 МБ).
- Playwright запускается через системный Chrome: channel="chrome" (встроенный Chromium не скачан).
- В body есть data-rate-date — не использовать селектор [data-rate-date] для текстовых узлов (был баг: затёрлась вся страница).
